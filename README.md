# Tracker for Pokémon TCG Pocket

**A simple web app to track a collection in Pokémon TCG Pocket.**


## 📝 About

**TCG Pocket Tracker** is a project to track a player's collection of Pokémon in the mobile card game collection app Pokémon TCG Pocket. The goal of the application is to provide an easy, interactive way to track the player's card count, compare to the collection of friends, and get statistical insights.


## 📂 Features

- 📝 **Tracking** – Track the Pokémon card count from Pokémon TCP Pocket.
- 📊 **Stats** – Receive insights on pack completion and other statistics.
- 👥 **Comparison** – Compare different packs with friends to find cards to trade.


## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/screetox/TCG-pocket-tracker.git
cd TCG-pocket-tracker
```

### 2. Install the requirements
Install the required python packages:
```bash
pip install -r requirements.txt
```

### 3. Run the app
Launch the local development server via Streamlit:
```bash
streamlit run app.py
```

### 4. Access the Application
Once the app is active, open your web browser and navigate to [http://localhost:8501/](http://localhost:8501/).
